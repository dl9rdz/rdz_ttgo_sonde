Why rdzTTGOsonde?

Built for radiosonde enthusiasts, with a focus on practical use in the field and easy integration into tooling. Decodes RS41, RS92, M10, M20, DFM6/9/17, MP3-H1. Since 2019.

Standalone device

  • Runs entirely on ESP32 + SX127x
  • For portable and stationary use
  • Integrated web UI
  • WiFi connectivity

User interfaces

  • Integrated map view in web UI
  • Dedicated Android app rdzSonde
  • Coming soon: iPhone app
  • aprsmap on Windows, Linux, and macOS
  • Chasemapper

Data backends

Data can be sent directly from the ESP32 to:

  • APRS (radiosondy etc)
  • Sondehub
  • MQTT
  • …and more
